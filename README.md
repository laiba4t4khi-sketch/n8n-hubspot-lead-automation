# n8n + HubSpot - Lead Capture Automation

Hello everyone!

In this project, I built a complete Lead Capture and CRM Automation using n8n and HubSpot.

**How it Works:**
The workflow starts with a Webhook that receives lead data in real-time, and instantly creates or updates the contact in HubSpot CRM using the Create or Update Contact action.

This automation saves 2+ hours of manual work daily, prevents lead leakage, and keeps the CRM 100% organized.

**Proof of Execution:**
I verified the execution in n8n - Execution ID 330, Status: Succeeded - and confirmed the contact `Laiba Test` was automatically created in HubSpot.

I build practical, no-code automation solutions using n8n, HubSpot, and Webhooks to help businesses save time.
